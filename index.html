Selected research projects

NLP · Research contribution · 2024

DynaMoE-LPE: few-shot question answering

Code

Contributed to a framework combining dynamic attention, a simplified mixture of experts, and learnable positional encoding. Work included tokenisation, span alignment, and fine-tuning transformer models with limited training samples.

Transformers · Few-shot QA · Mixed precision

Technical details

January–December 2024. Work included a 10k-vocabulary BPE tokenizer, span alignment, adaptive masking, and fine-tuning BERT-family models on limited samples using cosine annealing, gradient clipping, and early stopping.

Computer vision · Independent dissertation · 2023–2024

SETI radio-signal classification

Code

Developed a three-branch CNN ensemble to classify seven types of radio-signal spectrograms. The workflow included class balancing, leakage checks, multi-seed evaluation, bootstrap confidence intervals, and Grad-CAM interpretation.

Approximately 95% classification accuracy reported in the project experiments.

TensorFlow · CNN ensembles · Grad-CAM

Technical details

June 2023–April 2024. Combined InceptionResNetV2, ResNet50, and MobileNetV2 with SpecAugment, class balancing, MD5 leakage checks, multi-seed evaluation, bootstrap confidence intervals, and Grad-CAM interpretation.

Time-series modelling · Academic project · 2025

Time-series forecasting of NVIDIA stock prices

Code

Compared LSTM, XGBoost, and ARIMA using historical Alpha Vantage data, with stationarity checks, seasonal decomposition, and feature engineering.

LSTM achieved a reported MAPE of 1.32% in the project evaluation.

Python · LSTM · XGBoost · ARIMA

Technical details

January–April 2025. Preprocessing, stationarity checks, seasonal decomposition, feature engineering, and model evaluation. The reported error is specific to this experiment; it is not a guarantee of future forecasting performance.

Reported model results relate to each project’s experimental setup; they do not imply performance on new datasets or future market data.
